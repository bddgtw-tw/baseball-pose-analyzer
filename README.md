# 棒球動作分析器 MVP

正式頁面：https://bddgtw-tw.github.io/baseball-pose-analyzer/

## 三項功能

1. 選擇本機影片，或在手機上點「拍攝影片」使用系統相機錄製；載入後自動辨識骨架，顯示左右手肘與膝蓋的 2D 夾角。
2. 播放、前後 1 格或 5 格、循環，以及 0.10×、0.25×、0.50×、0.75×、1.00× 速度。
3. 下載目前畫面的骨架 PNG，或將影片與骨架合成後下載。影片格式依瀏覽器支援為 MP4 或 WebM。

影片在裝置瀏覽器中處理，不會送往本專案的伺服器。程式及姿態模型由 CDN 載入，需要網路。影格率由播放畫面估算，未取得估值前以 30 fps 暫代；單鏡頭 2D 姿態與骨盆位置不能當作 3D 重心或醫療判斷。
