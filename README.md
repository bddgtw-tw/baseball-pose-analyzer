# 棒球 AI 姿態逐幀分析器 (Baseball Pose Analyzer)

基於 Google MediaPipe 的純前端棒球動作分析工具。專為基層少棒、青少棒教練與選手家長設計。

## 功能特點
- **33 點骨架辨識**：自動追蹤全身關節，標註手肘、前膝與軀幹。
- **逐幀格放（Frame-by-Frame）**：支援按幀微調（鍵盤 `←` / `→`），精準捕捉擊球與著地瞬間。
- **即時力學角度**：自動計算左右手肘夾角、前膝煞車伸展角度、軀幹側傾角度。
- **純本地運算**：免上傳伺服器、零流量消耗、100% 保障私人訓練影片隱私。
- **匯出分享**：支援高解析度關鍵幀截圖（PNG）與完整帶骨架動態影片（MP4/WebM）。
