# 棒球動作影片分析器（Baseball Pose Analyzer）

以瀏覽器為主的棒球影片觀察工具，提供逐格檢視、動作階段標記、畫面註記與單鏡頭 2D 姿態估算，適合教練與家長一起回看影片。

## 分析流程

1. 選擇球員投球或打擊影片，鏡頭固定並讓全身入鏡。
2. 使用慢速播放、時間軸或逐格按鈕找出關鍵時點。
3. 在「準備、跨步落地／引棒蓄力、出手／擊球、收勢」標記動作階段。
4. 查看可辨識的左右手肘、所選前腳膝角與軀幹傾角，並比較同一影片不同階段的變化。
5. 使用畫面註記與截圖，和球員討論一個具體觀察。

## 數據如何解讀

- 姿態模型提供 33 個人體關節點；關節遮擋或信心不足時，數值會顯示「—」。
- 角度是由單一攝影機畫面推算的 2D 投影，不是 3D 動作捕捉，也不會判定動作好壞或給球員評分。
- 角度會受拍攝方向、鏡頭高度、遮擋與影片品質影響。適合在相同拍攝視角下比較同一球員的動作階段或前後影片，不應直接當作傷病診斷或通用理想值。
- 影格率會優先依播放時收到的影片畫面估算；估算前以 30 fps 暫代。瀏覽器的逐格定位與影片來源影格率仍可能有差異，請以時間與畫面確認關鍵時點。

## 隱私與網路

影片在瀏覽器中處理，應用程式不會將影片上傳到分析伺服器。頁面會從 CDN 載入 MediaPipe、Tailwind 等程式與模型，因此初次使用需要網路連線，也會使用網路流量。請避免在共用裝置留下未清除的私人影片。

## 支援功能

- 本機影片與瀏覽器鏡頭輸入
- 慢速播放、逐格前後移動與時間軸定位
- 投球／打擊階段書籤與角度變化摘要
- 關節角度標籤、手動畫線與畫面截圖
- 匯出帶骨架影片（可用格式依瀏覽器支援而定）

此工具是教練討論與影片回看的輔助工具；最後仍需由教練依球員年齡、能力、傷病史與訓練目標判讀。
